# Ledgerline Talent — CA / CS / Tax staffing website

Open `index.html` in any browser. No build step and no internet needed except for Google Fonts (falls back to system fonts offline).

```
index.html
assets/
  css/style.css        all styles (60-30-10 palette tokens at the top)
  js/main.js           animations, parallax, scroll reels, form handling
  js/vendor/           gsap, ScrollTrigger, lenis (local copies)
  images/              all photos (Unsplash, free licence), stored locally
```

Before launch: replace brand name, email/phone and service promises; connect both forms (`#hireForm`, `#cvForm` in main.js) to a backend or email service.
